# Python Projects

Three small projects I built while learning Python.

## Contact book
A command-line contact book that saves contacts to a JSON file. Supports add, show all and search.
Run: `python contact_book.py`

## File organiser
Sorts a messy folder into sub-folders by file type. Has a preview mode and never overwrites files.
Run: `python organiser1.py`

## Sales report
Reads a sales CSV with pandas, calculates revenue per product and per day, and saves charts.
Put your own `sales.csv` in `test_folder/Spreadsheets/` with the columns: date, product, quantity, price.
Run: `python sales_report.py`
